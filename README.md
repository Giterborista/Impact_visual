# Zosurabalpin evidence–impact visualization

Interactive visualization comparing evidence reliability with the climate-change contribution of reconstructed activities in the Zosurabalpin product system.

The page contains two views:

- **Activity-added contribution:** additive contributions that reconcile with the final HTP10 climate-change result.
- **Cumulative branch contribution:** overlapping upstream branch contributions that must not be summed.

## Deploy on Render

Create a **Static Site** connected to this repository and use:

- Build command: leave empty
- Publish directory: `.`

The site is a single self-contained `index.html` file.
